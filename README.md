## ⚙️ Installation and Setup

### Prerequisites

Install Python 3 and Git on your system.

### 1. Clone the Repository

```bash
git clone https://github.com/dilkashshekh11/Matplotlib-and-Seaborn-Learning-Journey.git
```

### 2. Navigate to the Project Folder

```bash
cd Matplotlib-and-Seaborn-Learning-Journey
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 4. Install Required Libraries

```bash
pip install numpy pandas matplotlib seaborn jupyter
```

### 5. Start Practicing

```bash
jupyter notebook
```

Alternatively, open the repository in VS Code and run your Python files or notebooks directly.
